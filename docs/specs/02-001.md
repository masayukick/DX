**規模の定義：**

- **大企業**：中小企業及び小規模事業者を除く、常時使用する従業員の数が二千人を超える会社及び個人
- **中堅企業**：中小企業及び小規模事業者を除く、常時使用する従業員の数が二千人以下の会社及び個人
- **中小企業**：中小企業基本法に基づく中小企業者（https://www.chusho.meti.go.jp/faq/faq/faq01_teigi.html）
- **小規模事業者**：中小企業基本法に基づく小規模企業者（https://www.chusho.meti.go.jp/faq/faq/faq01_teigi.html）
